02 · UI/UX Design

Interfaces, mapped before they're built.

From information architecture and user flows to wireframes and finished interfaces, these projects show how I work through the structure of an experience before designing and building it.

How I Work

Understand the User

Consider the user's goals, needs, and expectations so the structure is solving the right problem before I start designing screens.

Map the Structure

Organize the pages, content, and interactions into a clear structure, using sitemaps and user flows to work out how everything connects.

Build the Wireframes

Work through layout, hierarchy, and interactions in low-fidelity wireframes before committing to visual design or code.

Refine the Interface

Turn the structure into a finished interface, refining hierarchy, consistency, accessibility, and the details of how it behaves.

01

Caring for People

Website Redesign · Wireframes

Figma · Wireframing · Information Architecture

A website redesign for a coaching organization, focused on restructuring the site's navigation and page hierarchy. I mapped the main pages and user paths in Figma, with the goal of making services easier to find and the path to booking more direct.

Caring for People wireframe screens

Homepage — Reworked the homepage hierarchy to introduce the organization clearly and give visitors a more direct path into its services.

Services — Gave each service its own page while keeping the structure consistent between the two.

FAQ — Grouped common questions so visitors can find answers before reaching out. The navigation dropdown and accordion groupings mirror each other, so the menu previews what's inside.

About & Contact — Gave the organization's story and background a dedicated space, while keeping the contact experience short and straightforward.

02

Recipeas

Recipe-Sharing App · User Flows

Figma · User Flows · Wireframing

A recipe-sharing app concept developed as a team project. I focused on mapping the main user flow — finding a recipe, creating an account, and posting a recipe — before the team moved into detailed screen design.

Recipeas screens and user flow

Homepage — The initial wireframe explored browsing and filtering as the primary way to discover recipes. The structure was then carried into the more refined interface below.

Login — Kept the login screen focused on the information needed to access an account, without adding unnecessary steps.

Create a Dish — Structured the recipe form into a simple sequence: title, image, preparation time, ingredients, and instructions.

Full User Flow — Mapped the full path from entering the site through authentication and recipe creation, making the screens and decisions in the experience easier to plan as a team.
